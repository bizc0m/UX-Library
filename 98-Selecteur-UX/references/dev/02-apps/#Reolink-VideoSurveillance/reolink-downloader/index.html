Reolink Mass Downloader

Bienvenue dans l'interface de téléchargement en masse pour vos caméras Reolink.

Comment commencer :

  1. Ouvrez un terminal dans le répertoire du projet
  2. Exécutez la commande suivante :
./start.sh

OU si cela ne fonctionne pas, exécutez :

cd backend && npm start

Une fois le serveur lancé, ouvrez votre navigateur à l'adresse :

http://localhost:3000

Fonctionnalités disponibles :

  • Détection automatique des caméras sur le réseau local
  • Connexion sécurisée à la caméra Reolink
  • Visualisation des jours d'enregistrement
  • Sélection multiple de plages horaires
  • Détection automatique des types d'événements (motion, person, vehicle, etc.)
  • Téléchargement en masse avec suivi des progrès
Ouvrir l'interface

Note : Assurez-vous que votre caméra Reolink est accessible sur le réseau local avant de démarrer.
