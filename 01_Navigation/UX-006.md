# UX-006 — Accompagner les icônes ambiguës d’un libellé

Type : Bonne pratique · Version : 1.0 · Revue documentaire : 2026-09-07

## Problème
Une icône originale exige de deviner son sens.

## Bonne pratique
Ajouter un texte visible aux actions dont le symbole n’est pas clairement compris.

Source du principe : [N05 — NN/g — Icon Usability](https://www.nngroup.com/articles/icon-usability/). Nature : Recommandation.

## Pourquoi
La compréhension dépend du contexte et de l’expérience.

## À faire
- Tester le sens sans indice
- Conserver un nom accessible pour chaque commande

## À éviter
Une icône seule dont l’infobulle est le seul mode de découverte.

## Exceptions et limites
Des commandes très familières peuvent rester compactes après vérification d’usage.

## Exemple original, fictif
Bon : icône avec « Exporter ». Mauvais : hexagone abstrait pour sauvegarder.

## Checklist de vérification
- [ ] Identifier l’action sans survol
- [ ] Vérifier son nom avec un lecteur d’écran
- [ ] Conserver une preuve du résultat (capture, observation ou relevé) et les limites du test.
