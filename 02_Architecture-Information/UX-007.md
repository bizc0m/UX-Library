# UX-007 — Construire les catégories avec les modèles mentaux

Type : Bonne pratique · Version : 1.0 · Revue documentaire : 2026-09-07

## Problème
Le classement reproduit les équipes internes et disperse les contenus.

## Bonne pratique
Utiliser un tri de cartes pour explorer les regroupements compris par le public.

Source du principe : [N06 — NN/g — Card Sorting](https://www.nngroup.com/articles/card-sorting-definition/). Nature : Recommandation.

## Pourquoi
Le classement devient fondé sur des observations.

## À faire
- Choisir un échantillon de contenus réel
- Comparer les regroupements et les noms proposés

## À éviter
Traiter un tri de cartes comme une preuve de navigation réussie.

## Exceptions et limites
Des obligations documentaires peuvent imposer une structure ; prévoir alors des entrées orientées tâches.

## Exemple original, fictif
Bon : comparer « Factures » et « Achats ». Mauvais : publier les noms des services internes.

## Checklist de vérification
- [ ] Tester ensuite la recherche d’un contenu dans l’arborescence
- [ ] Consigner les catégories ambiguës
- [ ] Conserver une preuve du résultat (capture, observation ou relevé) et les limites du test.
