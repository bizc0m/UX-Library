# UX-048 — Prévenir les erreurs aux conséquences importantes

Type : Bonne pratique · Version : 1.0 · Revue documentaire : 2026-09-07

## Problème
Une action engageante est exécutée avant que la personne en comprenne la portée.

## Bonne pratique
Pour le périmètre de 3.3.4 AA, fournir réversibilité, vérification ou confirmation appropriée.

Source du principe : [W11 — W3C Understanding — 3.3.4 AA — error-prevention-legal-financial-data](https://www.w3.org/WAI/WCAG22/Understanding/error-prevention-legal-financial-data.html). Nature : Norme expliquée.

## Pourquoi
Une erreur ne doit pas devenir immédiatement irrécupérable.

## À faire
- Nommer les objets concernés
- Choisir une protection proportionnée

## À éviter
« Êtes-vous sûr ? » sans quantité ni conséquence.

## Exceptions et limites
Le critère vise certains engagements, données et réponses de test ; une confirmation pour chaque geste banal est inutile.

## Exemple original, fictif
Bon : « Supprimer ces 8 éléments » avec récupération. Mauvais : suppression générale sous « Nettoyer ».

## Checklist de vérification
- [ ] Tester annulation ou récupération
- [ ] Vérifier la portée réelle sur un jeu de données de test
- [ ] Conserver une preuve du résultat (capture, observation ou relevé) et les limites du test.

## Confiance et provenance
Élevée sur le critère cité ; application à vérifier dans le produit. Statut de consultation : Contenu consulté, le 2026-09-07.
La règle reprend le principe référencé. L’exemple, les actions et le protocole de test sont des adaptations originales ; ils ne constituent pas une étude publiée ni un résultat déjà observé.
