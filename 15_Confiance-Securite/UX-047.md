# UX-047 — Permettre une authentification sans épreuve cognitive imposée

Type : Bonne pratique · Version : 1.0 · Revue documentaire : 2026-09-07

## Problème
Le collage est bloqué ou le mot de passe doit être mémorisé sans aide.

## Bonne pratique
3.3.8 AA encadre les tests cognitifs : prévoir alternative ou mécanisme d’assistance, sous exceptions.

Source du principe : [W10 — W3C Understanding — 3.3.8 AA — accessible-authentication-minimum](https://www.w3.org/WAI/WCAG22/Understanding/accessible-authentication-minimum.html). Nature : Norme expliquée.

## Pourquoi
Les outils d’assistance peuvent soutenir l’authentification.

## À faire
- Autoriser gestionnaire et collage
- Rendre les erreurs récupérables

## À éviter
Exiger de recopier un code sans possibilité d’assistance.

## Exceptions et limites
Le critère comporte notamment des exceptions de reconnaissance d’objets et de contenu personnel ; ne pas le résumer à une interdiction de tout CAPTCHA.

## Exemple original, fictif
Bon : code collable et aide à la connexion. Mauvais : six cases qui empêchent le collage.

## Checklist de vérification
- [ ] Tester un gestionnaire de mots de passe
- [ ] Coller le code complet et corriger une erreur
- [ ] Conserver une preuve du résultat (capture, observation ou relevé) et les limites du test.
