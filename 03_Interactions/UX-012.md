# UX-012 — Proposer une alternative au glisser-déposer

Type : Bonne pratique · Version : 1.0 · Revue documentaire : 2026-09-07

## Problème
Déplacer un objet exige un geste continu difficile.

## Bonne pratique
Selon 2.5.7 AA, offrir une opération à pointeur simple sans glisser, sauf exception applicable.

Source du principe : [W02 — W3C Understanding — 2.5.7 AA — dragging-movements](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html). Nature : Norme expliquée.

## Pourquoi
Le déplacement reste possible avec une précision motrice limitée.

## À faire
- Ajouter « Déplacer vers… »
- Rendre la destination explicite

## À éviter
Croire qu’une alternative clavier suffit à elle seule pour ce critère de pointeur.

## Exceptions et limites
Le glisser peut rester disponible ; l’exception concerne notamment une fonction essentielle ou un contrôle non modifié de l’agent utilisateur.

## Exemple original, fictif
Bon : sélectionner puis choisir le dossier. Mauvais : déposer sur une cible minuscule obligatoire.

## Checklist de vérification
- [ ] Déplacer sans maintenir le pointeur
- [ ] Vérifier aussi le parcours clavier séparément
- [ ] Conserver une preuve du résultat (capture, observation ou relevé) et les limites du test.

## Confiance et provenance
Élevée sur le critère cité ; application à vérifier dans le produit. Statut de consultation : Contenu consulté, le 2026-09-07.
