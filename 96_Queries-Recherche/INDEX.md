## Check avant ajout

- Le repo a une licence compatible.
- Le dernier commit ou release est recent.
- L'exemple fonctionne hors contexte marketing.
- Le code peut etre extrait sans importer toute l'application.
- Les effets ont un fallback sans animation.
- Les scrapers respectent le cadre legal et technique de la source.
