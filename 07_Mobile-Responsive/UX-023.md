# UX-023 — Permettre le reflow au zoom

Type : Bonne pratique · Version : 1.0 · Revue documentaire : 2026-09-07

## Problème
Le texte agrandi exige des déplacements dans deux directions.

## Bonne pratique
Respecter 1.4.10 AA : reflow sans perte à 320 pixels CSS de large pour contenu à défilement vertical, sous réserves.

Source du principe : [W04 — W3C Understanding — 1.4.10 AA — reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html). Nature : Norme expliquée.

## Pourquoi
Le zoom reste utile aux personnes malvoyantes.

## À faire
- Laisser le texte se redistribuer
- Éviter les hauteurs fixes qui coupent la lecture

## À éviter
Masquer les contrôles importants à petite largeur.

## Exceptions et limites
Un tableau ou diagramme nécessitant deux dimensions peut relever d’une exception ; le reste de la page doit toujours s’adapter. Le cas horizontal prévoit 256 pixels CSS de haut.

## Exemple original, fictif
Bon : formulaire sur une colonne. Mauvais : bouton hors écran au zoom.

## Checklist de vérification
